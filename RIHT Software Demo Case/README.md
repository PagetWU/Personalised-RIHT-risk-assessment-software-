# De-identified RIHT Demonstration Case 002

This folder contains a strongly de-identified, thyroid-centred lower-neck ROI for demonstrating the RIHT software workflow. Direct identifiers and image metadata were removed, the physical origin was reset, and the face and remaining head-and-neck anatomy were excluded by cropping.

The clinical inputs used for the demonstration (age 55 years, gender unknown, N stage 2) are synthetic values and are not attributes of the source patient. The provided thyroid contour is an existing study contour.

Run the RIHT launcher with this folder as the case folder. The software will detect CT.mha, RTdose.mha, Thyroid_mask.mha, and the retained target masks automatically.

This is research demonstration material, not a clinical case report or treatment recommendation. Public distribution must remain consistent with the applicable ethics approval and institutional data-sharing policy.
